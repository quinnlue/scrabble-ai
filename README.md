# Scrabble AI

Upload the [demo notebook](output/jupyter-notebook/scrabble-colab-demo.ipynb) to Colab and choose **Runtime → Run all** on a CPU runtime. The notebook bundles the engine and word list. Use **Play AI move** to advance a turn, adjust the search settings between turns, or click **Reset** to start over. The opening check plays **QUIZ for 44 points** at depth 1.

The demo uses 51,742 words of 2–9 letters, adapted from Kevin Atkinson's English and American [SCOWL 2020.12.07](https://sourceforge.net/projects/wordlist/files/SCOWL/2020.12.07/). The upstream copyright and permission notice is bundled with the word list inside the notebook.
